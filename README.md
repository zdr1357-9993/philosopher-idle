# 🛋️ 철학과 키우기

> "철학과 가서 뭐 먹고 살래?" — 그 질문이 현실이 된 날부터 70세까지.

탭으로 노동하는 철학과 인생 키우기 게임 (웹 프로토타입).

## 플레이

`index.html`을 브라우저로 열면 된다. 빌드 과정 없음. GitHub Pages로 그대로 배포된다.

## 구조

| 파일 | 내용 |
|---|---|
| `data.js` | 국가 6개, 진로 트리(9갈래 17칸), 확률 이벤트, 거장 질문, 엔딩 20개 |
| `game.js` | 엔진: 월 단위 시간, 탭 노동, 숙련도, 확률 판정, 저장 |
| `style.css` | 거지 키우기풍 모바일 UI |

## 핵심 규칙

- **시간**: 1x 속도에서 25초 = 1개월. 22세 → 70세 은퇴까지 약 4시간.
- **탭 = 노동**: 본업 / 투잡 알바 / 독서 중 하나를 골라 탭한다. 체력이 닳고, 과로하면 멘탈이 닳는다.
- **진로 트리**: 교수가 되려면 석사 → 박사 → 시간강사 → 임용. 학원 원장은 과외 → 강사 → 창업.
- **숙련도**: 탭할수록 오르지만 높을수록 느리게 오른다. 작가는 글을 써도 돈이 안 오르고 글솜씨와 원고 진척도만 오른다.
- **확률과 변수**: 합격·승진·출판·조회수·투자는 전부 확률. 경기 지수와 철학 트렌드가 매달 움직인다. 유튜브는 1년 해도, 10년 해도 망할 수 있다.
- **엔딩**: 각 진로의 정상(피터 틸, 석학, 고전 작가…) + 실패 엔딩(영원한 시간강사, 만년 취준생, 디오게네스…) + 거장들에게 한 대답으로 갈리는 은퇴 엔딩.
