탭으로 노동하는 철학과 인생 키우기 (웹 프로토타입). 플레이: https://zdr1357-9993.github.io/philosopher-idle/

## 규칙 요약

- **25초 = 한 달**, 22세 → 70세. 월말에 월급·생활비·월세 정산.
- **탭 = 노동.** 본업을 탭하면 이번 달 노동 게이지가 차고 능력치가 오른다. 투잡 알바 탭 20번 = 알바 한 달 월급.
- **능력치 3개**: 🧠 학문 · 🗣️ 말 · 📊 실무. 높을수록 천천히 오른다.
- **본업 + 부업 2개**: 알바·과외·글쓰기·유튜브는 본업과 동시에. 하던 일이 다른 길로 새는 "갈림길" 이벤트(강의 영상 바이럴 → 유튜브, 출판 제안 → 작가, 기업 스카우트, 공동창업). 경력은 이직·조건에 반영.
- **확률**: 합격·승진·임용·출판·조회수·투자. 경기(호황/불황)와 철학 트렌드가 매달 움직인다.

## 나라별 현실 (게임에 반영된 것)

- 🇰🇷 한국: 논술 사교육 시장, 로스쿨(LEET), 윤리 임용 바늘구멍, 강사법 이후 강의 배정 끊김
- 🇯🇵 일본: 신졸 일괄채용 — 졸업 첫해 취업 확률 x2, 놓치면 "기졸" 페널티. 오버닥터·비상근강사
- 🇺🇸 미국: 학자금 빚, LSAT 강자인 철학과의 로스쿨 루트, 박사 펀딩, adjunct
- 🇫🇷 프랑스: 고3 철학 필수 → CAPES·agrégation·프레파 교사 루트, 명성 x2
- 🇩🇪 독일: 학비 무료, Promotion → Habilitation, 학술기간제법(12년) 시한, 김나지움 교사 수습
- 🇬🇧 영국: 3~4년 박사, 기간제 계약, 법조 전환 과정(SQE)
